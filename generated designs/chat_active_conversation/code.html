Can you explain how React Server Components work?
temp_preferences_custom Medha

React Server Components (RSC) introduce a new paradigm in React development by allowing components to render exclusively on the server. This shifts the rendering environment from the client (browser) to the server infrastructure.

Core Concepts

  • Zero Bundle Size: Server components don't ship their code to the client. Only the HTML/JSON output is sent.
  • Direct Backend Access: They can directly access databases or internal microservices without needing an API layer.
  • Automatic Code Splitting: Client components imported inside server components are automatically code-split.

Unlike traditional Server-Side Rendering (SSR) which happens once on initial load, RSCs can be re-fetched dynamically without losing client state. You define a client component using the 'use client' directive.

Here is a basic example of a Server Component fetching data directly, and importing a Client Component for interactivity:

// app/page.tsx (Server Component by default in Next.js App Router)
import db from '@/lib/db';
import LikeButton from './LikeButton';

export default async function Post({ id }: { id:: string }) {
  // Direct database access on the server
  const post = await db.query'SELECT * FROM posts WHERE id = ?', [id]);

  return <article className"p-4"<h1post.title</h1<ppost.content</p{/* Client component injected here */}
      <LikeButton initialLikes{post.likes} postId{id} />
    </article);
}
