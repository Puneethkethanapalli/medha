Can you explain the layering principle in UI design? I'm trying to avoid using shadows.
auto_awesome
Medha

The layering principle replaces shadows by using tonal density to communicate depth. Instead of projecting a shadow to lift an element, you alter its material brightness.

Core Tenets

  • horizontal_rule The Void (Background): The absolute lowest layer, usually pure black or near-black.
  • horizontal_rule The Canvas (Surface Low): The primary resting place for content.
  • horizontal_rule The Interactive (Surface High): Elevated elements like inputs or active cards.

By nesting higher tonal values inside lower ones, the human eye perceives an elevation shift without needing a blurry drop shadow.
