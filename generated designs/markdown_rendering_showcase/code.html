JavaScript Array Methods

Here are the most commonly used array methods:

The map method creates a new array from the results.

  • map() — transforms each element
  • filter() — removes elements that don't match
  • reduce() — accumulates into a single value
javascript 
// Using map to double values
const numbers = [1, 2, 3, 4];
const doubled = numbers.map(num => num * 2);
console.log(doubled); // [2, 4, 6, 8]

// Using filter for even numbers
const evens = numbers.filter(n => n % 2 === 0);
