Tonal Hierarchy

In the Monolith design system, we don't use shadows to create depth. Instead, we use a rigid monochromatic scale based on material density.

surface_container_low (#1C1B1D) is used for the foundational canvas, while surface_container_high (#2A2A2C) represents interactive elements layered above it.
